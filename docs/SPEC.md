# 台指期行為訓練遊戲 — 定案規格 v2.0

> v1.0（2026-08-01 上午）為美股版，經 grill-me 收斂封版。同日使用者裁定轉向台指期貨（ADR 0007），
> 架構下移一層：月K→日K 骨架改為 日K→日內。本檔為唯一真相源；修改任何決定前先讀 §9 決策互鎖。
> v1.0 原文見 git 歷史（commit 0f107e8）。狀態：規格封版，未開工。

## 0. 一句話定位

自用台指期貨行為訓練工具：用真實市場數據模擬「當下的你」——資訊不完整、不可回溯、帶槓桿與情緒做決定——並診斷「你說的」與「你做的」之間的落差。

**不是**：預測訓練器、回測器、公開娛樂遊戲（公開版為第二階段，架構預留但不實作）。

## 1. 核心資料架構（兩層）

1. **日K骨架（真實）**：台指期近月連續（TX 日盤）2010-01 至今真實日K OHLC＋成交量，約 4,000 根。來源 FinMind `TaiwanFuturesDaily`，一次性抓好存 `data/daily/TX.json` 靜態檔。只用日盤（盤後交易時段不納入，ADR 0007）。
2. **日內層（生成，遊戲真相層）**：布朗橋生成當日 5 分K路徑（日盤 08:45-13:45，60 根）。
   - log 價格空間，兩端錨死 `log(當日O)→log(當日C)`；波動率用 Parkinson 估計 `σ ≈ ln(H/L)/(2√ln2)`。
   - 隨機決定當日 H、L 落在日內哪兩段（順序隨機），切三段各跑布朗橋，拒絕採樣越界路徑（超過重試上限則 clip）。
   - 生成路徑的極值須還原當日真實 H/L；聚合須還原當日 OHLC。
   - **種子 = hash(關卡ID, 第幾次玩, 日期)**，確定性函數。重整頁面、重播結果完全一致。
   - **所有觸價判定（停損、限價、盤中維持保證金與強平）以生成日內層為準**；它同時是顯示層——本版只有這一層生成物，無更深的視覺層。
   - 單一標的（台指），**無多標的相關性問題**，v1.0 的共同市場因子機制移除。

## 2. 商品與遊戲形狀

### 商品（同一價格序列 × 三種契約）
| 商品 | 乘數 | 定位 |
|---|---|---|
| 大台 TX | NT$200/點 | 主力 |
| 小台 MTX | NT$50/點 | 部位微調 |
| 微台 TMF | NT$10/點 | 小資金開局；**全程可用**（2024-07 才上市，遊戲設定為全歷史開放，UI 註記時代錯置） |

### 劇本制 4 關（3-10 個月一關，按日推進，30-60 分鐘一局）
| 關 | 區間 | 訓練目標 |
|---|---|---|
| 疫情 | 2020-01 → 2020-06 | 崩盤中的槓桿存活：減碼、補保證金還是反手 |
| 熊市 | 2022-01 → 2022-10 | 陰跌凹單：無明確底部的空頭，最難 |
| 平淡 | 2017-03 → 2017-08 | 低波動不亂做；過度交易被成本磨死 |
| 閃崩 | 2024-05 → 2024-10 | 大漲後的 2024-08-05 史上最大跌點：持倉過夜的代價 |

- **無限模式**：隨機起點、玩家自訂結束。引擎統一為「任意起訖區間」，劇本只是預設參數。
- **時間推進**：按日推進，一天一根日K。日內層在觸價與強平判定時自動展開；玩家可點開任一日觀看日內路徑回放。**推進一律不可逆**。
- **結算日**（每月第三個週三）：近月部位自動轉倉（成本＝固定滑價＋手續費）或由玩家選擇平倉。
- **存檔**：無限模式單槽覆蓋式；劇本模式無中途存檔，中離作廢不計入曲線。
- **後見之明對策 = B2**：玩家知道年份與方向，考「做不做得到」。重玩換種子：日K不變、日內全部重擲——方向已知、盤中路徑未知，停損掃不掃得到、強平打不打得中，每局重新來過。

## 3. 評分：行為分（D）

報酬率只當事實陳述，不當評分。評分主軸＝**言行一致**。

### 開局作戰計畫（全點選，~20 秒）
- 目標：保本 / 穩定正報酬 / 翻倍 / 自訂
- 最大回撤（權益數）：10% / 20% / 30% / 不設限
- 停損規則：固定點數 -X 點 / 收盤跌破 N 日均線 / 論點失效才走 / 不設停損
- 加碼規則：不加碼 / 順勢加碼 / 逆勢攤平 / 僅論點強化時
- 保證金使用率上限：30% / 50% / 70% / 不設限
- 持倉過夜：可過夜 / 當日沖銷為主（過夜需理由）

### 論點欄（自由文字）
每次新開倉（含反手）時問：「一句話：為什麼是現在、為什麼是這個方向？」記錄，後續操作與其牴觸則記違背。

### 矛盾偵測（純規則，不用 LLM）
計畫自相矛盾時，大師以**預寫模板**噴人並要求修改，例：
- 「逆勢攤平」＋「回撤 10%」→ 矛盾（攤平必然放大回撤）
- 「保證金使用率 70%+」＋「回撤 10%」→ 矛盾（一根長黑就打穿）
- 「當日沖銷為主」＋「停損＝論點失效才走」→ 矛盾（當沖必須有價格停損）
不矛盾→零摩擦直接開局。

### 違背類型（全程機器比對）
凹單（觸停損未平）／計畫外交易（含無理由過夜、超口數）／風險失控（回撤或保證金使用率超計畫）／論點漂移（因價格而非論點改變方向）／攤平加碼（計畫外的逆勢加碼）。

### 呈現：跨局進步曲線
單局分數不是重點；顯示歷次行為分、各違背類型次數的演變，突顯「N 局都沒改掉的那一項」。→ 需玩家檔案系統（profile.json）。

## 4. 保證金引擎與壓力機制

- **保證金（近似制，README 註明）**：原始保證金 ≈ 契約價值 × 10%（＝指數 × 乘數 × 0.10）、維持保證金 ≈ 原始 × 0.75。隨指數水準自動浮動，不手工整理歷史公告表。
- **每日結算**：收盤後按結算價逐日洗價；權益數低於維持保證金 → 追繳通知，次日補足或砍倉。
- **盤中強平**：權益數（按生成日內路徑逐段計）跌破維持保證金且無可用資金 → 強制平倉，順序＝**未實現虧損最大的部位優先**，砍到權益回到維持保證金以上為止。生成路徑判定（§1），重玩會不同。
- **轉倉**：結算日自動轉倉，成本＝固定滑價（1-2 點）＋手續費。「買著不動」在期貨中不存在，每次轉倉都是被迫重新決策的觸點。
- **交易成本真實**：手續費（大台/小台/微台 各檔位，開局可自訂，附常見價目預設）＋期交稅（契約價值 × 十萬分之二）。目的是懲罰過度交易——平淡關的主要死法。
- **現金流 = C**：每月固定投入（模擬薪水）＋整局最多一次重大衝擊事件（如「兩週內必須提出 30 萬」），觸發時機偏好在帳面虧損最大時。保證金被抽走時「砍哪個部位」本身就是診斷。
- **起始資金**：開局由玩家輸入真實金額量級，讓虧損數字有痛感。微台的存在讓小資金也玩得動。

## 5. 資訊層

- **價格**：真實日K＋生成日內（§1）。
- **籌碼（真實，每日）**：期貨三大法人（外資/投信/自營）多空淨部位，FinMind `TaiwanFuturesInstitutionalInvestors`。台指期決策標配，也是 OPMAN/謝孟恭評語素材。
- **總經**：台灣（央行重貼現率、CPI、失業率）＋美國（聯邦基金利率）。來源 FinMind 台灣總經數據集＋FRED（fredgraph.csv 免金鑰），存 `data/macro.json`。
- **事件卡**：每月 2-3 張、共約 600 張（2010 至今），台灣市場脈絡（含影響台股的國際事件），LLM（DeepSeek 管線）一次性預生成存 repo。
  - **鐵則：當時口吻**。禁止任何後見之明措辭。✅「武漢傳出不明肺炎病例，市場關注有限」❌「這是史上最快熊市的開端」。
  - **嚴格檢查工序**：關鍵詞黑名單比對（開端/史上最大/隨後/事後證明…）＋ LLM 複審一輪，不過就重生成。一張漏餡的卡毀掉一整關。
- **砍掉**：個股基本面（無個股）、選擇權鏈（第二版再議，OPMAN 完整發揮需要它）。

## 6. 大師評語

- **遊戲本體零 AI 依賴**：矛盾偵測與中途介入全走規則＋預寫模板。無金鑰、無網路、無延遲。
- **複盤走戰報**：結算輸出戰報 .md（開局計畫、逐筆交易與違背標記、保證金使用率軌跡、違背統計、歷次對照曲線）到 `reports/`，回 Claude Code 以 `/複盤` skill 讓大師評語。
- **預設三位**：Livermore（期貨投機本業：停損執行/趨勢/加碼紀律）、OPMAN（台指格局判讀/資金控管/凹單放到歸零）、謝孟恭（部位管理/心態/資訊判讀）。Dalio 退居選配；林沖留給現股當沖版；Buffett/Graham/Lynch 與本商品無關，不上。
- 無限模式：每月一次行為評分；累積違背達閾值觸發模板介入。

## 7. 平台與落地

- **純靜態網頁，零後端**：原生 JS（或極簡框架）＋ lightweight-charts。無建置步驟也能玩，開 index.html 即可。
- **File System Access API（A1）**：開局授權一次 repo 資料夾，之後 `reports/*.md` 與 `profile.json` 自動寫入。目標環境 Windows + Chrome/Edge。
- 目錄結構：
  ```

  reports/   profile.json
  tools/     ← 資料抓取與事件卡生成管線（Python，開發期用）
  ```

## 9. 決策互鎖（改任何一項前必讀）

1. **生成日內 ⇄ 重玩機制**：日內重擲是「方向已知、執行未知」的地基。若觸價改用真實日內資料，重玩＝背答案，行為分失效。
2. **行為分 ⇄ 後見之明（B2）**：評「執行」不評「預測」，才允許已知年份與方向。若改成報酬評分，B2 崩潰（等 2020-03-19 低點全押＝滿分）。
3. **保證金近似制 ⇄ 訓練安全**：保證金設太鬆（比率過低、不強平）＝教玩家重倉凹單，在真實市場歸零。動保證金參數前先想這條。
4. **劇本無中途存檔 ⇄ 行為分**：能讀檔重來就能洗掉違背紀錄。
5. **生成日內是唯一觸價判定層**：禁止混入任何真實日內資料（不可「考據當天實際走勢」修正路徑），否則 §9-1 被侵蝕且重玩一致性破裂。

## 10. 里程碑切分（開發依賴序）

- M1 資料管線：TX 日K（2010 至今）＋三大法人籌碼＋台美總經 → 靜態 JSON
- M2 生成引擎：布朗橋日內 5 分K＋種子系統（統計性質測試：聚合還原當日 OHLC、極值還原 H/L、同種子一致）
- M3 保證金引擎：口數撮合、逐日洗價、追繳、盤中強平、轉倉、交易成本、現金流（**本版最大工程**）
- M4 行為系統：作戰計畫表單、矛盾偵測、違背比對、行為分
- M5 UI：日K圖＋籌碼副圖、推進控制、日內回放、三商品下單面板
- M6 事件卡管線：生成＋嚴格檢查（可與 M2-M5 並行）
- M7 戰報與檔案：戰報 .md 輸出、profile.json、跨局曲線
- M8 複盤 skill：`/複盤` 指令＋三位大師流程
