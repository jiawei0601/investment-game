# 投資行為訓練遊戲 — 定案規格 v1.0

> 2026-08-01 經 grill-me 完整逼問收斂。本檔為唯一真相源；修改任何決定前先讀「決策互鎖」一節。
> 狀態：規格封版，未開工。

## 0. 一句話定位

自用投資行為訓練工具：用真實市場數據模擬「當下的你」——資訊不完整、不可回溯、帶情緒做決定——並診斷「你說的」與「你做的」之間的落差。

**不是**：預測訓練器、選股回測器、公開娛樂遊戲（升級公開版為第二階段，架構預留但不實作）。

## 1. 核心資料架構（三層）

1. **月K骨架（真實）**：2010-01 至今的真實月K OHLC，約 199 個月。來源 yfinance/stooq，一次性抓好存 `data/monthly/*.json` 靜態檔。
2. **日K層（生成，遊戲真相層）**：布朗橋生成月內日K。
   - log 價格空間，兩端錨死 `log(O)→log(C)`；波動率用 Parkinson 估計 `σ ≈ ln(H/L)/(2√ln2)`。
   - 隨機決定 H、L 落在月內哪兩天（順序隨機），月份切三段各跑布朗橋，拒絕採樣越界路徑（超過重試上限則 clip）。
   - **共同市場因子**：各標的日內殘差由單一市場因子驅動＋自身 beta＋特異噪音，禁止各標的獨立隨機（否則盤面假）。
   - **種子 = hash(關卡ID, 第幾次玩, 標的, 年月)**，確定性函數。重整頁面、重播結果完全一致。
   - 所有成交、停損、結算以日K判定。
3. **日內視覺層（生成，純顯示）**：點開某日才 lazy 生成分鐘級走勢，錨住當日 OHLC，同 seed 保證重看一致。**不參與任何成交判定**。

## 2. 遊戲形狀

- **劇本制** 4 關（每關 1-2 年，30-60 分鐘一局）：
  | 關 | 區間 | 訓練目標 |
  |---|---|---|
  | 疫情 | 2020-01 → 2020-12 | 崩盤中該不該接刀 |
  | 熊市 | 2021-11 → 2022-10 | 陰跌中該不該停損（無明確底部，最難） |
  | 平淡 | 2010-01 → 2011-12 | 不要亂做；本關最優解常是「什麼都不做」 |
  | AI | 2023-01 → 2024-06 | 該不該追已漲多的東西 |
- **無限模式**：隨機起點、玩家自訂結束。引擎統一為「任意起訖區間」，劇本只是預設參數。
- **時間推進**：預設按週推進，事件日自動降速到日（單日振幅超閾值、持股財報日、FOMC 決議日）。**推進一律不可逆**。
- **存檔**：無限模式單槽覆蓋式；劇本模式無中途存檔，中離作廢不計入曲線。
- **後見之明對策 = B2**：承認玩家知道方向（用真實標的名稱、玩家知道年份），考「做不做得到」。重玩換種子：月K不變、日K全部重擲——方向已知、執行未知。

## 3. 評分：行為分（D）

報酬率只當事實陳述，不當評分。評分主軸＝**言行一致**。

### 開局作戰計畫（全點選，~20 秒）
- 目標：保本 / 打敗買進持有 / 翻倍 / 自訂
- 最大回撤：10% / 20% / 30% / 不設限
- 停損規則：跌破成本 -X% / 跌破 N 日均線 / 論點失效才走 / 不設停損
- 加碼規則：不加碼 / 上漲加碼 / 下跌攤平 / 僅論點強化時
- 單檔上限：20% / 33% / 50% / 不設限

### 論點欄（自由文字）
第一次買進某標的時問：「一句話：為什麼是現在、為什麼是它？」記錄，後續操作與其牴觸則記違背。

### 矛盾偵測（純規則，不用 LLM）
計畫自相矛盾時，大師以**預寫模板**噴人並要求修改，例：
- 「論點失效才走」＋「回撤 10%」→ 矛盾
- 「下跌攤平」＋「回撤 10%」→ 矛盾
- 「翻倍」＋「單檔 20%」＋「不加碼」→ 幾乎不可能
不矛盾→零摩擦直接開局。

### 違背類型（全程機器比對）
凹單（寫了停損沒執行）／計畫外交易／風險失控（回撤超計畫）／論點漂移（因價格而非論點改變行為）。

### 呈現：跨局進步曲線
單局分數不是重點；顯示歷次行為分、各違背類型次數的演變，突顯「N 局都沒改掉的那一項」。→ 需玩家檔案系統（profile.json）。

## 4. 壓力機制

- **槓桿/做空用標的池表達**：TQQQ/SQQQ/UPRO/SH。不做融資、維持率、追繳、借券引擎。波動耗損由真實槓桿 ETF 數據自然呈現。
- **現金流 = C**：每月固定投入（模擬薪水）＋整局最多一次重大衝擊事件（如「兩週內必須提出 30 萬」），觸發時機偏好在帳面虧損最大時。強迫賣出時「賣賺的還是賣賠的」本身就是診斷（處分效應）。
- **交易成本真實**：美股免手續費含價差；（台股第二版：0.1425% 手續費＋0.3% 證交稅）。目的是懲罰過度交易。
- **起始資金**：開局由玩家輸入真實金額量級，讓虧損數字有痛感。

|---|---|---|
| 指數/資產 ETF | ~9 | SPY, QQQ, IWM, GLD, TLT, SGOV, BTAL…（含使用者退休計畫核心倉，可在遊戲內跑真實策略） |

## 6. 資訊層

- **價格**：月K→生成日K（§1）。
- **總經**：FRED API（利率、CPI、失業率、殖利率曲線），免費乾淨，存靜態 JSON。
- **事件卡**：每月 2-3 張、共約 600 張，LLM（DeepSeek 管線）一次性預生成存 repo。
  - **鐵則：當時口吻**。禁止任何後見之明措辭。✅「亞洲某些工廠傳出停工，影響尚待評估」❌「這是史上最快熊市的開端」。
  - **嚴格檢查工序**：關鍵詞黑名單比對（開端/史上最大/隨後/事後證明…）＋ LLM 複審一輪，不過就重生成。一張漏餡的卡毀掉一整關。
- **砍掉**：基本面（免費歷史財報不可得，且行為分不需要它）、籌碼（美股無資料，市場間不對稱）。第二版再議。

## 7. 大師評語

- **遊戲本體零 AI 依賴**：矛盾偵測與中途介入全走規則＋預寫模板。無金鑰、無網路、無延遲。
- **複盤走戰報**：結算輸出戰報 .md（開局計畫、逐筆交易與違背標記、違背統計、歷次對照曲線）到 `reports/`，回 Claude Code 以 `/複盤` skill 讓大師評語。
- **預設三位**：Livermore（停損執行/紀律）、謝孟恭（部位管理/凹單/心態）、Dalio（驅動因子分散/賭單一情境）。Buffett/Graham/Lynch 因無基本面暫不上；林沖/OPMAN 留給台股版。
- 無限模式：每月一次行為評分；累積違背達閾值觸發模板介入。

## 8. 平台與落地

- **純靜態網頁，零後端**：原生 JS（或極簡框架）＋ lightweight-charts。無建置步驟也能玩，開 index.html 即可。
- **File System Access API（A1）**：開局授權一次 repo 資料夾，之後 `reports/*.md` 與 `profile.json` 自動寫入。目標環境 Windows + Chrome/Edge。
- 目錄結構：
  ```
  index.html + app.js（或 src/ 極簡拆分）
  data/monthly/*.json  data/macro.json  data/events/*.json
  reports/   profile.json
  tools/     ← 資料抓取與事件卡生成管線（Python，開發期用）
  ```

## 9. 決策互鎖（改任何一項前必讀）

1. **隨機日K ⇄ 重玩機制**：日K重擲是「方向已知、執行未知」的地基。若改用真實日K，重玩＝背答案，行為分失效。
2. **行為分 ⇄ 後見之明（B2）**：評「執行」不評「預測」，才允許使用真實標的名稱＋已知年份。若改成報酬評分，B2 崩潰（空手等 3/23 全押＝滿分）。
3. **地雷股 ⇄ 訓練安全**：倖存者偏差下「任何下跌都會回來」。刪地雷股＝教玩家在真實市場歸零。
4. **劇本無中途存檔 ⇄ 行為分**：能讀檔重來就能洗掉違背紀錄。
5. **日內視覺層不參與成交 ⇄ 停損公正性**：生成的假影線若能掃停損，玩家被不存在的價格處決。

## 10. 里程碑切分（開發依賴序）

- M1 資料管線：44 檔月K抓取＋FRED＋地雷股手工資料 → 靜態 JSON
- M2 生成引擎：布朗橋日K＋共同因子＋種子系統（可獨立測試：統計性質驗證）
- M3 撮合與帳務：買賣、成本、現金流、衝擊事件
- M4 行為系統：作戰計畫表單、矛盾偵測、違背比對、行為分
- M5 UI：K線圖、推進控制、事件日降速、日內視覺層
- M6 事件卡管線：生成＋嚴格檢查（可與 M2-M5 並行）
- M7 戰報與檔案：戰報 .md 輸出、profile.json、跨局曲線
- M8 複盤 skill：`/複盤` 指令＋三位大師流程
