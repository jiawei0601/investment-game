# 7. 轉向台指期貨（美股版 → 台指期版）

狀態：已採納（2026-08-01，使用者裁定）

## 脈絡

v1.0 為美股 44 檔月K骨架版，已經 grill-me 收斂封版（`docs/SPEC.md` 舊版、git 歷史 commit 0f107e8）。封版當日，使用者裁定整案轉向台指期貨：從「多標的、月K骨架＋生成日K」改為「單一標的（台指）、真實日K骨架＋生成日內」，架構下移一層。本 ADR 記錄轉向本身的裁決與後續連鎖後果，取代 v1.0 的多項既定決策。SPEC.md 已改寫為 v2.0，是唯一真相源；本 ADR 補上「為什麼轉向」與「轉向後哪些舊決策作廢／修訂」的紀錄。

## 決策

### 使用者裁決（四項，2026-08-01 當面裁定）

1. **真相層下移一層**：真相層＝真實日K（台指期近月連續，TX 日盤）＋生成日內（布朗橋，日盤 5 分K）。所有觸價（停損、限價、盤中維持保證金、強平）以生成日內層為準；日K層只作為錨點與逐日結算依據。取代 v1.0「真實月K＋生成日K」的骨架層級。
2. **時間範圍 2010 至今**：與 v1.0 相同起點，不變。
3. **微台 TMF 全程可用**：TMF 實際 2024-07 才上市，但遊戲設定全歷史區間可交易，UI 須註記「時代錯置」，換取小資金開局的可玩性。
4. **只做日盤**：不納入盤後交易時段，降低資料與撮合複雜度。

### 主對話定案的例行判斷（承接上述裁決的技術落地，非另行裁決）

- **保證金近似制**：原始保證金 ≈ 契約價值 × 10%、維持保證金 ≈ 原始 × 0.75，隨指數水準自動浮動，不手工整理歷史保證金公告表（SPEC §4）。
- **連續近月自動轉倉**：結算日（每月第三個週三）近月部位自動轉倉，成本＝固定滑價＋手續費；玩家可選擇改為平倉（SPEC §2）。
- **劇本縮至 3-10 個月**：因為骨架精度從月K提升到日K，劇本區間相應縮短（v1.0 為年度級別），改為疫情／熊市／平淡／閃崩四關（SPEC §2）。
- **大師陣容改為 Livermore／OPMAN／謝孟恭**：期貨槓桿與紀律訓練與台股當沖／台指選擇權社群語彙更貼近；Dalio 退居選配，林沖（現股當沖）留給第二版，Buffett／Graham／Lynch 與期貨商品無關，不上（SPEC §6）。
- **籌碼資訊層加回**：期貨三大法人（外資/投信/自營）多空淨部位為台指期決策標配資料，FinMind 有現成公開資料集，加回資訊層（SPEC §5）。

## 後果

- **保證金引擎成為最大工程（M3）**：v1.0 的美股版沒有保證金與強平機制（現貨買賣），v2.0 因為是期貨槓桿商品，口數撮合／逐日洗價／追繳／盤中強平／轉倉／交易成本全部要重新設計實作，是本版工程量最大的模組（SPEC §10 M3）。
- **44 檔標的池與地雷股防呆作廢**：ADR 0004 定案的「多標的含地雷股防倖存者偏差」機制在單一標的（台指）架構下不再適用——指數期貨不會下市歸零，ADR 0004 正式廢止（Superseded by 本 ADR），歸零教育改由保證金引擎的強平機制承接（SPEC §9-3）。
- **共同市場因子機制移除**：ADR 0002 定案的「多標的間用共同市場因子＋beta＋特異噪音」模型，在單一標的下完全沒有存在必要，v2.0 生成引擎不需要處理跨標的相關性。
- **OPMAN 完整發揮需要選擇權鏈（第二版）**：OPMAN 的核心思維框架建立在台指選擇權買方策略上，v2.0 只做期貨（無選擇權鏈資料），OPMAN 複盤只能發揮格局判讀／資金控管／凹單診斷這部分，選擇權相關洞見要等第二版補上選擇權鏈資料才能完整發揮。
- **微台全程可用是時代錯置，非資料還原**：TMF 2024-07 才真實上市，v2.0 為了小資金開局可玩性刻意設定全歷史可用，這是遊戲性妥協而非史實重建，UI 必須明確標註，不可讓玩家誤以為 2010 年就能交易微台。
