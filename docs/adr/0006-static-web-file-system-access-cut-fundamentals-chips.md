# 6. 純靜態網頁＋File System Access API，砍基本面與籌碼

狀態：已修訂（見 0007）

> 2026-08-01 轉向台指期貨（ADR 0007）：純靜態網頁與 File System Access API 部分不變。資訊層決策改變——個股基本面持續砍（無個股），但選擇權鏈也一併砍（第二版再議）；原本因美股無公開籌碼來源而砍掉的籌碼資料，因台指期有 FinMind 公開三大法人資料集而加回，見 SPEC v2.0 §5。

## 脈絡

這是自用工具，目標是「開 index.html 就能玩」，不想背負伺服器成本、建置流程、部署管線。但遊戲又需要跨局持久化（profile.json、歷次戰報）——沒有後端資料庫的情況下，要嘛整個放棄跨局功能，要嘛找一個瀏覽器端能直接寫本機檔案的方法。同時，資訊層要放什麼資料也要有取捨：基本面財報免費歷史資料拿不到，籌碼資料美股沒有對應的公開來源。

## 決策

- **純靜態網頁，零後端**：原生 JS（或極簡框架）＋ lightweight-charts。無建置步驟，開 index.html 即可玩。
- **File System Access API（A1）**：開局授權一次 repo 資料夾，之後 `reports/*.md` 與 `profile.json` 自動寫入，不需每次操作重新授權。目標環境限定 Windows + Chrome/Edge。
- **砍掉基本面**：免費歷史財報資料不可得，且行為分（ADR 0003）本來就不需要它。
- **砍掉籌碼**：美股沒有對應的免費籌碼資料，若只在台股放籌碼會造成市場間資訊不對稱（v1 只做美股，見 ADR 0004），籌碼整組留給第二版。

目錄結構：
```
index.html + app.js（或 src/ 極簡拆分）
data/monthly/*.json  data/macro.json  data/events/*.json
reports/   profile.json
tools/     ← 資料抓取與事件卡生成管線（Python，開發期用）
```

## 後果

- 換來真正零摩擦的部署：沒有伺服器托管成本、沒有建置管線，資料就位後完全離線可玩。
- 代價：File System Access API 把玩家鎖死在 Chromium 系桌面瀏覽器——Firefox、Safari、行動裝置都不支援，這是硬性平台限制，必須在文件與 UI 上明講，不能之後被誤當成「順手就能修的相容性 bug」。
- 代價：砍掉基本面資料直接連動 ADR 0005 的後果——**Buffett/Graham/Lynch 大師評語第一版無法上**，這是本決策造成的下游限制，兩條 ADR 互相印證、不可只改一邊。
- 代價：沒有基本面／籌碼資料，代表這個遊戲架構永遠無法長成「價值投資訓練」或「台股籌碼訓練」模組，除非另開一個資料蒐集專案——這是 v2 的範圍，SPEC §0 說的「架構預留但不實作」不代表加回這些資料是低成本的事，屆時等同重新做一次 M1。
- 代價：純靜態＋零後端的架構，若未來真的要做公開多人版本（SPEC §0 明確排除於 v1），不是加個 API 就好，是整個持久化與資料分發模型要重做，不是漸進式擴充。
