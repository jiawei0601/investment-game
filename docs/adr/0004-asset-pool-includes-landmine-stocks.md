# 4. 標的池含地雷股、防倖存者偏差

狀態：已廢止（Superseded by 0007）

> 2026-08-01 轉向台指期貨（ADR 0007）：單一標的（台指期）架構下無多標的池，指數期貨無倖存者偏差問題（指數不會下市歸零）。本 ADR 全文作廢，歸零教育改由保證金引擎的強平機制接手（SPEC v2.0 §9-3）。

## 脈絡

如果標的池只放「後來都活下來」的股票，遊戲會在不知不覺中教出一個致命直覺：任何下跌都會回來，攤平永遠是對的。這在真實市場是會讓人歸零的錯覺（SPEC §9-3）。免費資料源（yfinance/stooq）預設只服務還在市場上的標的，下市股票通常直接消失或抓不到完整歷史，要故意把地雷股放進池子需要額外的手工資料整備工作。

## 決策

第一版標的池 44 檔，全部美股，六層分類（SPEC §5）：

| 層 | 數量 | 內容 |
|---|---|---|
| 指數/資產 ETF | ~9 | SPY, QQQ, IWM, GLD, TLT, SGOV, BTAL… |
| 槓桿/反向 | ~4 | TQQQ, SQQQ, UPRO, SH |
| 大型權值 | ~15 | AAPL, MSFT, NVDA, GOOGL, AMZN, JPM… |
| 高波動題材 | ~8 | TSLA, COIN, PLTR, ARKK… |
| **地雷股（必做）** | ~6 | Hertz, Bed Bath & Beyond, SVB, Peloton, Zoom/Teladoc 類 |
| 加密 | 2 | BTC, ETH |

地雷股是**必做項目**，不是可選的調味——SPEC §9-3 明訂拿掉地雷股等於在教玩家錯誤的直覺，是五條互鎖之一，不可為了資料取得方便而妥協。已下市標的需手工補資料。

台股（含 FinMind 籌碼、林沖/OPMAN 評語）明確列為第二版，第一版不混市場——避免美股與台股資料完整度不對稱造成的體驗落差。

## 後果

- 換來遊戲的核心防呆機制：玩家會在劇本或無限模式中真實撞見「這次沒有回來」的標的，打破倖存者偏差直覺。
- 代價：地雷股資料需要人工蒐集——下市後 yfinance/stooq 通常無資料，得靠 Stooq 歷史封存檔、SEC 申報文件、或手動整理 CSV，資料品質與缺口風險比其餘 38 檔高得多，且無法用同一套自動化管線批次處理（見 M1 backlog）。
- 代價：地雷股一旦被玩家識破「這是遊戲特別安排的雷」，可能會條件反射式迴避，反而學不到東西——這個風險本 ADR 不解決，需要 M4/M6 之後靠劇本設計與事件卡口吻去緩解，不是資料層能處理的問題。
- 代價：44 檔僅美股，台股使用者要等 v2，且 v2 沒有時程承諾；跨市場混用在 v1 明確排除，不能因為「反正都是抓資料」就臨時加台股標的進池子。
