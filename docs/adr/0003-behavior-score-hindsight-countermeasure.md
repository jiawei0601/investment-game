# 3. 行為分為評分主軸、B2 後見之明對策

狀態：已修訂（見 0007）

> 2026-08-01 轉向台指期貨（ADR 0007）：核心決策（行為分為評分主軸、B2 後見之明對策）不變。下文「月K骨架不變、日K全部重擲」請對應理解為「日K骨架不變、日內全部重擲」（見 ADR 0002 修訂註）；「SPY」僅為例示，v2.0 單一標的為台指期，不影響決策本體。

## 脈絡

這是一個「診斷言行落差」的訓練工具，不是預測訓練器或回測器（SPEC §0）。若照一般投資遊戲的做法用報酬率評分，會撞上兩個問題：

1. 玩家使用真實標的名稱、已知年份（例如 2020 年的 SPY），天然帶後見之明——知道 3 月會急跌又急漲。用報酬率評分，最優解永遠是「空手等最低點全押」，這不是在測玩家的行為，是在測玩家記不記得歷史。
2. 報酬率無法反映「說一套做一套」——凹單、計畫外交易、風險失控、論點漂移這些真正想訓練的東西，跟最終賺賠沒有必然關係（運氣好的凹單一樣賺錢）。

## 決策

評分主軸改為**行為分（D）**，報酬率只當事實陳述、不進入評分公式（SPEC §3）。具體機制：

- **開局作戰計畫**（全點選，~20 秒）：目標、最大回撤、停損規則、加碼規則、單檔上限，五項皆為預設選項。
- **論點欄**：首次買進某標的時強制填「一句話：為什麼是現在、為什麼是它？」，後續操作與其牴觸則記違背。
- **矛盾偵測**：純規則＋預寫模板，不用 LLM。計畫自相矛盾時擋在開局前噴人並要求修改；不矛盾則零摩擦直接開局。
- **違背類型**（全程機器比對，非人工判定）：凹單（寫了停損沒執行）／計畫外交易／風險失控（回撤超計畫）／論點漂移（因價格而非論點改變行為）。
- **跨局進步曲線**：單局分數不是重點，重點是歷次行為分與各違背類型次數的演變，需要玩家檔案系統（profile.json）。
- **B2 後見之明對策**：不迴避玩家知道方向這件事，而是承認它，把測驗目標從「猜對方向」改成「做不做得到」。重玩換種子時月K骨架不變（方向已知）、日K全部重擲（執行細節未知），見 ADR 0002。
- **無中途存檔**：劇本模式不可中途存檔，中離作廢不計入曲線（SPEC §9-4）——能讀檔重來就能洗掉違背紀錄，行為分會失去意義。

## 後果

- 換來報酬率不再是作弊誘因：空手等 3/23 全押不會拿高分，因為評的是執行過程而非結果。
- 代價：規則式矛盾偵測必然不完備——只能抓預先想到的矛盾組合（如「論點失效才走」+「回撤 10%」），玩家仍可能組出偵測不到但精神上矛盾的計畫；模板文字也必然比真人教練生硬，需要持續補案例而非追求一次到位。
- 代價：無中途存檔意味著任何當機、瀏覽器當掉、誤關分頁都會讓整局作廢——這是刻意的取捨（防止洗紀錄），必須在 UI 上明確告知玩家，不能被誤認為 bug。
- 代價：跨局進步曲線依賴 profile.json 持久化，這又依賴 File System Access API 落地（ADR 0006）；沒有檔案寫入能力，行為分機制的「跨局」價值就折損成單局工具。
- 代價：新增任何開局計畫選項或違背類型，都要回頭檢查矛盾偵測模板是否需要對應新增組合，否則會出現「明明矛盾卻放行」的漏洞——這是規則庫要背的持續維護成本。
