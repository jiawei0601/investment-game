# 0008 — H/L 落點依條件分佈加權抽樣；禁止 clip 貼邊直線

狀態：已採納（2026-08-02，opus 複核 M2 後修訂規格）

## 脈絡

M2 初版依 SPEC v2.0 §1 原文「隨機決定 H、L 落點（順序隨機）」實作為均勻隨機。opus 獨立複核以參考模擬（60 步高斯橋、條件於 max≈H/min≈L、每天 12 萬次）驗證：

- 70% 的交易日，真實 P(先觸H) < 0.10 或 > 0.90，均勻 50/50 與真實條件分佈平均偏離 0.411。
- 後果：約 30% 的交易日生成「真實機率 <5%」的路徑。因 H 與 L 當日必被觸及，括號單（停損＋停利）的勝負完全由 H/L 先後決定——趨勢日多單被「先衝高再殺低」假掃損的頻率遠高於現實。B2 重玩重擲會反覆強化假訊號，教出「停損沒用、要放很寬」的錯誤結論，直接違反訓練安全（§9-3 精神）。
- 另：clip fallback 在 1.1% 的日子（43/4062）把整段路徑壓成貼在 H/L 的水平線（最壞 55/61 個點釘在當日最低），盤中權益數與強平判定失真數小時。

橋接數學本身經複核為精確（線性去趨勢＝精確布朗橋，條件變異數 t(T−t)/T 成立），RNG（cyrb128+sfc32）逐行比對無誤——缺陷在錨點擺放與 fallback，屬規格層錯誤。

## 決策

1. (idxH, idxL) 與先後順序改為**依「布朗橋在時刻 k、m 同時等於 logH、logL」的二維高斯聯合密度加權抽樣**（60×60 權重表，純函數、確定性）。複核時已實測此法重現參考模擬（例：0.000/1.000/0.726 vs 參考 0.000/0.999/0.714）。
2. 拒絕採樣重試耗盡時，fallback 改為**縮小該段 σ 重抽**（或等效解析抽樣），並以測試斷言「clip 後不得出現連續 >3 個貼邊 knot」。
3. 生成路徑的已實現波動率須校準至全資料集平均比值落在 [0.9, 1.1]（初版系統性偏高 19%）。
4. 5 分K 須帶自然影線（初版 60 根全為純實體，當日極值只可能落在 knot 上，視覺一眼假）。

## 後果

- 生成成本增加（權重表 ~3,600 次運算/日＋子步抽樣），仍在瀏覽器毫秒級，可接受。
- 同種子的輸出與初版不相容——初版尚未發佈、無存檔相容問題，不設遷移。
- 測試必須加分佈檢定（H/L 落點與先後的分佈、全資料集硬約束掃描、clip 日自然案例），不能只驗端點還原。
