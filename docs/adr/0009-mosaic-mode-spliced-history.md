# 0009 — 馬賽克模式：真實月份隨機拼接的反記憶行情

狀態：已採納（2026-08-02，使用者提案）

## 脈絡

劇本模式的後見之明對策是 B2（承認玩家知道方向，考執行）。使用者提出第三種模式：玩家連「方向」都不該知道——從隨機起始日開始，暖身約一個月真實行情後，後續每個月塊改為從全部歷史月份隨機抽樣（對數報酬結構縮放錨定到當前指數水位），使記憶中的行情無從對照。

## 決策

1. 新模式 `mosaic`：種子抽起始日 → 暖身段（約一個月）真實行情 → 拼接段（月塊種子抽樣＋縮放，首開=前收，整數點）。
2. 抽樣/縮放/日內全部走 `hash('mosaic', attempt, …)` 確定性種子；同 attempt 重玩一致。
3. 合成日曆沿真實交易日曆延伸；結算日/轉倉/月入金機制不變；引擎與保證金/行為分模組零改動——mosaic 只是 dailyRows 產生器。
4. **資訊層歸零**：馬賽克模式全程不顯示事件卡、籌碼、總經。理由：拼接段的行情與任何真實月份的新聞/籌碼都對不上；若只在拼接段隱藏，「資訊消失的那一天」本身就洩漏現實結束點。全程沒有＝無從對照。
5. 不在 UI 標示暖身段與拼接段的邊界（標示即洩漏）。

## 修訂（2026-08-02，同日）：月塊抽樣改體制條件 Markov

使用者質疑均勻抽樣破壞走勢動態連續性——真實市場月間有動能延續與波動叢聚（2022 連跌 10 個月），均勻抽樣會教出「趨勢不會持續」的錯誤直覺（與地雷股防倖存者偏差同類問題）。裁決：

- 月塊按「月報酬方向 × 波動高低」分四體制（up_calm/up_vol/down_calm/down_vol），從真實相鄰月統計 4×4 轉移矩陣（Laplace 平滑），拼接時先按轉移機率抽體制、再從該體制池抽具體月份（禁連抽同源月）。
- 統計性質像真實（趨勢延續、波動叢聚），具體路徑仍不可預測，反記憶目的不受損。
- `sampling='markov'`（預設）| `'uniform'`（保留對照）。

## 後果

- 訓練光譜補齊：劇本模式=已知方向練執行；馬賽克模式=未知方向練流程與紀律。
- 拼接段的宏觀連貫性不存在（可能連續抽到三個大跌月），屬特性非缺陷——極端序列正是壓力測試。
- 事件卡/籌碼素材在此模式無用武之地；OPMAN/謝孟恭複盤評語中的籌碼視角對此模式的戰報不適用（戰報標注模式供 /複盤 判別）。
- 玩家若認出暖身段的真實區間，只能推斷暖身段本身——拼接段與起始日期無關，記憶優勢止於第一個月塊邊界（且邊界不可見）。
